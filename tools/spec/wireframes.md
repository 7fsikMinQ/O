## 2. 핵심 화면 와이어프레임

> 표기: `[ ]` 버튼/입력, `( )` 칩/토글, `●` 상태점, `▼` 열림. 폭 360dp 기준. 이모지는 버튼·상태에 적극 사용(토스·당근식).

### SCR-H01 홈 (출연자 앱)
```text
┌──────────────────────────────┐
│ 안녕하세요, 길동님 👋     🔔3 │
│ 오늘 지원 가능한 현장 12건      │
├──────────────────────────────┤
│ ⚡ 긴급  내일 06:00 경기 파주  │
│   [가제] 정장 형사 5명 · 시급 10,320 │
├──────────────────────────────┤
│  < 2026년 11월 >               │
│  일  월  화  수  목  금  토     │
│  8   9  [10] 11  12  13  14    │  ← 날짜 아래 숫자 뱃지(공고 수)
│      ●   ●3  ●2                │  ← 내 상태점: 🟢합격 🟡지원 🔵출석
│ 20~22일 막대: 🏕 2박3일 (숙박)   │  ← 다일 일정은 걸친 날짜에 막대 표시
├──────────────────────────────┤
│ 11월 10일 (월) · 4건            │
│ (내 조건만 ●ON) (지역) (역할)   │
│ ┌──────────────────────────┐ │
│ │ 🎬 [가제] 정장 형사 · 5명   │ │
│ │ 06:00~12:00 · 파주 · 시급 12,000 │ │
│ │ (🌙심야)(🏕숙박)  지원 8  ♡ │ │
│ └──────────────────────────┘ │
├──────────────────────────────┤
│  홈   공고   내일정   알림   MY │
└──────────────────────────────┘
```

### SCR-H04 공고 상세 (비공개 현장 기본)
```text
┌──────────────────────────────┐
│ ←                       ♡  ⋯ │
│ [가제] 사극 A 현장 🔒          │
│ 보출AAA                        │
│ 11/10(월) 22:00 ~ 11/11(화) 06:00 🌙 │
│ 지역: 경기 파주 (상세는 합격 후 공개)  │
├─[일정 1]─[일정 2]────────────┤
│ ▣ 정장 형사 (남) 5명            │
│   1980~1995년생 · 170~185cm · 65~80kg │
│   머리: 단발/중간 · 문신 없는 분 │
│   시급 10,320 (최저시급) · 9시간 이내 8시간분 고정 │
│   비고: 점심·저녁 식대 제공, 교통비 별도 … │
│   ✔ 내 조건 충족               │
├──────────────────────────────┤
│ [        지원하기 ✍️        ] │
└──────────────────────────────┘
```
미충족 시 CTA 비활성+사유("몸무게 조건이 맞지 않아요 ⚖️"). 미성년은 "만 19세 이상부터 지원할 수 있어요".

### SCR-H05 지원하기 (바텀시트 단계형) + SCR-H32 서명
```text
┌ 1/3 내 정보 확인 ─────────────┐
│ 이름 홍길동 · 010-1234-5678     │
│ 성별 남 · 1990년생 · 178cm/72kg │
│ 사이즈 100 / 32 / 270            │
│ 집주소 서울 강남구 …        [수정]│
│ 집합지 [사당역 1번 출구      ✎] │
│ 정산 계좌  ◉ 내 정보에서 가져오기 │
│              국민 123-****-**89 │
│            ○ 다른 계좌 입력      │
│              [은행▼][계좌번호][예금주] │
│ ⚠ 같은 날 09:00~14:00 다른 지원과 겹쳐요 │
├ 2/3 현재 사진 📷 (필수) ───────┤
│ [촬영] [앨범]  ▢▢▢ (자동 압축)  │
│ 한마디 [검정 정장 보유        ]  │
├ 3/3 서명 ✍️ ─────────────────┤
│ 위 내용이 사실임을 확인하고 서명합니다 │
│ ┌────────────────────────┐ │
│ │      (서명 패드)         │ │
│ └────────────────────────┘ │
│ [지우기]        [ 서명하고 지원 완료 ] │
└──────────────────────────────┘
```

### SCR-H27 합격 통보 확정/거절
```text
┌──────────────────────────────┐
│ 🎉 합격했어요!                  │
│ [가제] 사극 A · 정장 형사       │
│ 11/10(월) 06:00 집합            │
│ 아래 시간까지 확정해 주세요     │
│ ⏰ 오늘 21:00까지 (남은 3시간)  │
│ [      확정하기 ✅      ]      │
│ [  어렵겠어요 🙏  ]            │
└──────────────────────────────┘
```
일정 연기로 이동된 건은 "일정이 11/12로 바뀌었어요. 확정해야 참여가 확정돼요" 문구로 같은 화면 사용.

### SCR-H28 일정 충돌 경고 (확인할 때까지 1시간마다)
```text
┌──────────────────────────────┐
│ ⚠️ 시간이 겹치는 일정이 있어요   │
│ ① 사극 A   11/10 06:00~12:00    │
│ ② 현대극 B 11/10 09:00~14:00    │
│ 두 곳 모두 확정된 상태예요.      │
│ 업체 두 곳에도 알림이 갔어요.    │
│ [ 확인했어요 ]                  │
│ [ ②를 취소할래요 ] [ ①을 취소 ] │
└──────────────────────────────┘
```

### SCR-F08 / F05 출근·퇴근 세션과 스캔 (현장 모드)

```text
│ [ 출근 열기 ▶ ]  (열림 06:00~)  │

│ 방금: ✅ 김철수 출근 06:02       │
│ [미체크 목록] [수기 보정] [닫기]│

```

### SCR-C03 공고 작성 마법사 (업체 웹)
```text
 ① 가제 ──② 일정 ──③ 역할 ──④ 검토
┌───────────────────────────────────────────────┐
│ 일정 + 추가  [이전 공고 복사]                     │
│ ┌ 시작 2026-11-10 22:00  종료 2026-11-11 06:00 (8시간) 🌙 □숙박 ┐│
│ │ 집합지 [          ]  담당 반장 [김반장 ▼]          ││
│ │ 역할 + 추가                                          ││
│ │ ┌ 정장 형사 ─ 5명 ─────────────────────────┐ ││
│ │ │ 성별(남) 출생연도 [1980]~[1995] 키 [170]~[185]  │ ││
│ │ │ 몸무게 [65]~[80] 머리 ☑단발 ☑중간 □긴 □삭발   │ ││
│ │ │ 문신 ◉무관 ○없는 사람만                          │ ││
│ │ │ 시급 ◉최저시급(2026: 10,320원) ○직접입력        │ ││
│ │ │  → 9시간 이내 근무 시 82,560원 고정             │ ││
│ │ │ 비고 [점심·저녁 식대 제공 …]  의상 [검정 정장]    │ ││
│ │ │ 집합 override: 시간 [ ] 장소 [ ]                 │ ││
│ │ └──────────────────────────────────────┘ ││
│ └───────────────────────────────────────────────┘│
│ [임시저장]                       [이전] [다음]    │
└───────────────────────────────────────────────┘
```
일정이 1시간 미만 또는 21일 초과면 입력 단계에서 즉시 오류.

### SCR-C07 지원자 그리드 (업체 웹)
```text
┌ 정장 형사 · 정원 5 · 통보 2 · 확정 1 · 지원 8 ──(카드|●그리드)┐
│ ☐ 사진 이름   📞휴대폰       성별 나이 키  몸  노쇼 패널티 충돌  상태  │
│ ☑ [📷] 김철수 010-1234-5678   M   35  178 72   0     0      -    지원  │
│ ☑ [📷] 박영희 010-2222-3333   F   29  165 52   1     0   ⚠겹침  지원  │
│ ☐ [📷] 이민수 010-4444-5555   M   41  172 70   0     1      -   통보🟡 │
├──────────────────────────────────────────────────────────────┤
│ 선택 2건  [합격 통보] [불합격]        [마감하기(미통보 자동 불합격)]      │
└──────────────────────────────────────────────────────────────┘
```
휴대폰은 지원 단계부터 보이고, 집주소·계좌·주민번호는 합격 통보 이후 권한자만. 불합격은 사유 입력 없음.

### SCR-C12 메시지 / SCR-C25 메시지함
```text
┌ 메시지 보내기 ───────────────────────┐
│ 대상 (●확정자 전체)(통보자 포함)(참석 미확인)(마감 후 가용)(직접 선택) │
│ 수신 예정 38명                                   │
│ 제목 [집합 장소 변경 안내]  내용 […]              │
│ 채널 ☑ 앱 알림 ☑ 푸시                             │
│                              [미리보기][발송]    │
├ 발송 내역 ───────────────────────────┤
│ 11/09 18:02 집합 장소 변경 · 38명 · 읽음 29 · 답장 3 │
└──────────────────────────────────────┘
```
출연자의 답장은 메시지함에 모인다. 출연자가 먼저 보낼 수는 없다.

## 3. 공통 상태 배지 (색은 15번 문서 토큰, 이모지 병기)
| 상태 | 문구 | 색 |
|---|---|---|
| APPLIED | 📝 지원 완료 | 중립 |
| SELECTED | 🎉 합격 통보 (확정 대기) | 라벤더 |
| CONFIRMED | ✅ 확정 | 민트 |
| REJECTED / AUTO_REJECTED | 🍃 선발되지 않았어요 / 마감 | 회색 (경고색 금지) |
| EXPIRED | ⏰ 기한 만료 | 회색 |
| CANCELED_* | 취소 | 회색 취소선 |
| 참석 확인 | 👍 확인됨 / ⏳ 미응답 | 민트 / 피치 |
| 출석 | ✅ 출근 / 🕒 지각 / ❌ 노쇼 | 민트 / 피치 / 로즈 |
| 충돌 | ⚠️ 시간 겹침 | 피치 |
