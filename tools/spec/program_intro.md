## 구성 원칙
- **모듈러 모놀리스**: 하나의 Spring Boot 배포 단위, 모듈은 패키지로 분리. 모듈 간 호출은 **공개 서비스 인터페이스 또는 도메인 이벤트**로만 하고 **쓰기는 소유 모듈만** 한다.
- **의존 방향**: `api → application → domain ← infra`. `common` 은 모든 모듈이 참조 가능하되 `common` 은 어떤 모듈도 참조하지 않는다.
- **배치**는 모두 `@Scheduled` + ShedLock(DB 락)으로 다중 인스턴스에서도 1회만 실행되고, 실행 결과는 로그/메트릭으로 남긴다.
- 프런트는 OpenAPI 에서 생성한 타입 클라이언트만 사용한다(수기 DTO 금지).
