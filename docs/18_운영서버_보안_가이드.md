# 18. 운영 서버 · 비용 · 보안 · 포트포워딩 (v1.3)

> 질문: "운영 서버는 어디에, 얼마에, 어떻게 해야 보안 문제없이 되나? 포트포워딩도 해야 하나?"
> 가격은 2026-10-28 웹 확인값(◐/⭐ 구분은 [16번](./16_외부사실_확인표.md)). 착수 시 재확인.

## 1. 한 줄 답
- **서버: AWS Lightsail 서울 2GB 월 US$12 로 시작**(폐쇄 베타), 사용자가 늘면 4GB US$24 로 올림. 
- **포트포워딩은 하지 않는다.** 서버는 클라우드(공인 IP 있음)이므로 필요 없고, **집·노트북을 서버로 열면 안 된다**(집 IP 노출, 공유기 침해, 개인정보 유출 위험). 
- **개발 DB 는 노트북 WSL2** 에서만, 운영 DB 는 클라우드 서버 안에서 **외부에 포트를 열지 않는다.**

## 2. 구성
```
사용자 ─HTTPS→ Cloudflare(DNS·WAF·CDN) ─→ Lightsail 서울 [Caddy/nginx → Spring Boot → PostgreSQL(같은 서버, 127.0.0.1)]
                                         └ 정적 웹(업체·관리자, Flutter 웹)은 Cloudflare Pages
파일: Cloudflare R2(비공개, 서명 URL)   백업: pg_dump 암호화 → R2 (다른 계정 권한)
```
- 외부에 여는 포트: **443(필요 시 80→443)만**, 또는 **Cloudflare Tunnel 로 0개**(서버가 밖으로만 연결, 무료, 방화벽 인바운드 전부 닫기 가능). 권장: 터널 + 방화벽 인바운드 0 + SSH 는 키 인증 + 본인 IP 허용 또는 Lightsail 브라우저 SSH.
- DB(5432)·관리 콘솔·Docker 소켓은 **절대 외부 공개 ✕**. compose 에서 `127.0.0.1:5432:5432` 또는 포트 매핑 자체를 제거(내부 네트워크만).
- 다운 시간 허용 범위가 커서 단일 서버 허용. **백업이 곧 가용성** — 일 1회 암호화 덤프 + 주 1회 복구 리허설.

## 4. 보안 체크리스트 (운영 오픈 전 필수)
1. OS: 자동 보안 업데이트, 불필요 서비스 제거, root SSH 금지, 비밀번호 로그인 금지(키만), fail2ban.
2. 방화벽: Lightsail 방화벽에서 인바운드 443(+SSH 본인 IP) 외 전부 차단. 터널 사용 시 인바운드 0.
3. 앱: HTTPS 강제(HSTS), CORS 허용 도메인 고정, 쿠키 HttpOnly·Secure·SameSite, 로그인 시도 제한, 파일 업로드 MIME·크기·악성 검사, 서명 URL 만료 짧게.
4. 비밀: `.env`/키는 저장소 ✕. 운영 비밀은 서버 파일 권한 600 또는 AWS SSM Parameter Store/Secrets Manager. 개발·운영 키 분리. **주민번호 암호화 키는 DB 와 다른 곳**(서버 환경변수/Secrets), 키 버전 관리.
5. DB: 앱 전용 계정(최소 권한), 슈퍼유저 원격 접속 ✕, 연결은 localhost/내부망, 백업은 암호화(+오프사이트).
6. 로그: 주민번호·계좌·토큰 마스킹, 로그 보존 기간 설정, 접속 로그는 감사 테이블.
7. 관리자 보호: 관리자 로그인은 추가 인증(2차 인증) 권장, IP 제한 가능하면 Cloudflare Access.
8. 모니터링: UptimeRobot(무료)·디스크·백업 성공 알림. 장애 연락처.
9. 침해 대비: 유출 시 신고(개인정보보호법), 키 교체 절차, 복구 계획(11번).
10. **개발 데이터에 운영 개인정보 복사 ✕** (익명화 시드만).

## 5. 포트포워딩 FAQ
| 질문 | 답 |
|---|---|
| 운영 서버에 포트포워딩이 필요한가? | 아니다. 클라우드 VM 은 공인 IP 가 있고 방화벽 규칙(443)만 연다. |
| 집 PC/노트북을 서버로 쓰면? | 하지 않는다(공유기 침해·IP 노출·정전/끊김·개인정보 책임). |
| 폰으로 개발 중인 앱을 테스트하려면? | 같은 Wi-Fi + WSL2 mirrored networking, 또는 **Cloudflare Tunnel/ngrok 임시 URL** — 포트포워딩 없이. 테스트 후 중단. |
| 운영 DB 에 노트북에서 접속하려면? | SSH 터널(`ssh -L`) 또는 Lightsail 접속 후 psql. DB 포트 직접 개방 ✕. |

## 6. 대안
- GCP e2(무료 한도 f1-micro 제한적)·Oracle 무료 티어는 가용성·정책 변동 위험 → 개인정보 서비스에는 비추천.
- 사용자 수 증가 시: DB 분리(Lightsail Managed DB 또는 RDS) → 앱 2대 + LB. 현재 불필요.
