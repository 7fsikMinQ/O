# 20. 초기 세션 핵심 (새 세션이 가장 먼저 읽을 요약 · v1.3)
> 전체 기억은 루트 `CLAUDE.md`. 이 문서는 구현 착수용 핵심 + 일부 상세.

## A. 필수 (바꾸면 안 되는 것)
1. **서비스**: 보조출연 헬프. 업체가 공고 → 출연자가 현재 사진+전자서명으로 지원 → 업체 **합격 통보(SELECTED)** → 출연자 **확정(CONFIRMED)**. 예비·선착순·불합격 사유 없음. 마감 시 미선발 `APPLIED`→`AUTO_REJECTED`.
2. **시간은 예상**: 공고·합격서에 집합 ±2시간·종료 ±4시간, "확정 아님·변동·연장 가능" 문구. 정확한 종료 시각 노출 ✕.
3. **합격서에 금액 없음.** 보수는 공고에만(시급·최저시급: 근무 시작 연도 값, 9시간 이내 시급×8시간). **근로계약서는 현장 실물 — 서비스에 없음.**
4. **돈**: 플랫폼은 임금을 받거나 보관·송금하지 않는다. 정산 기록·이체 파일·원천징수는 만들되 `feature_flags` 기본 OFF(서버 404). `PAYOUT_EXECUTION` 구현 ✕.
5. **개인정보**: 휴대폰=지원 단계부터 업체 열람, 계좌·주소=합격 통보 후, 주민번호=항상 마스킹(전체는 OWNER/MANAGER+사유+감사+암호화 엑셀), 가입 필수 ✕(첫 지원 전 등록). 로그에 주민번호·계좌·토큰 ✕.
6. **겹침**: 겹치거나 간격 짧으면(기본 120분) 둘 다 확정 가능하되 양쪽 업체 알림+출연자 확인까지 1시간마다 경고. DB EXCLUDE(override 제외) + 앱이 override 포함 전체 검사.
7. **QR 출퇴근**: 업체 구성원 누구나 세션 열기, 인원별 30초 회전 QR. 메시지는 업체→출연자 시작만.
8. **로그인**: 출연자 휴대폰+문자 숫자 6자리, 업체·관리자 이메일+비밀번호. 스토어: 계정 삭제(앱+웹)·처리방침 공개·심사 데모 계정·Play API 36(21번).
9. **추가 기능**: 지도·전화 버튼, 공지 읽음 확인·재안내, ⭐ 출연자.
10. **UI**: 주 사용층 20~40대, 쉬운 한국어(19번 용어 사전), 글씨 16px·버튼 52px, 파스텔·다크.

## B. 기술·환경
- Spring Boot 4.1 + Java 25 + PostgreSQL 18(모듈러 모놀리스, Flyway, 아웃박스). 출연자 Flutter(앱+웹 CanvasKit, W2 iPhone 실기기 게이트), 업체·관리자 React.
- 개발: 노트북 WSL2 + Docker Engine(포트 127.0.0.1만, 운영 데이터 복사 ✕). 운영: Lightsail 서울 US$12 + Cloudflare, 인바운드 443(또는 터널 0), DB 비공개, 포트포워딩 ✕(18번).
- 스키마 v1.3: 테이블 72·뷰 2·시험 27건. 변경 시 `schema.sql`+시험+`tools/build_docs.py`+`tools/verify_all.sh`.

| 주제 | 값 |
|---|---|
| 일정 길이 | 1시간~21일, KST 생성열 `start_date/end_date` |
| 허용 오차 | `gather_tolerance_minutes`=120, `end_tolerance_minutes`=240 |
