## 검토에서 나온 결정 변경 요약
1. 중복 확정 방지: 날짜 유니크 → 일정 유니크(사용자안) → **시간 범위 EXCLUDE** (최종)
2. 예비합격: 마감 자동 불합격에서 **제외**
3. 미성년자: 플래그 → **동의서 테이블 + 3개 임계 설정**
4. 구독: boolean 컬럼 → **기능 행 + 사용량 집계**
5. 색상 토큰: 대비 미달 색 교체
6. 웹 프레임워크: Next.js 권고 철회 → Vite SPA (v0.2 에서 이미 변경, 유지)
