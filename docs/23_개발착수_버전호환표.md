## 3. 결정 변경 (확인 결과)
1. **QueryDSL 보류**: Boot BOM 이 5.1.0 을 관리하지만 해당 릴리스는 사실상 비유지보수(5.0.0 노트에 "2년 넘게 방치"), Hibernate 7.4 와의 호환 근거 없음. 포크(OpenFeign 7.x)는 존재하나 호환 미검증 → **v1 은 Spring Data JPA + `JdbcClient` 네이티브 SQL**. (이 설계는 EXCLUDE·range·SKIP LOCKED 등 네이티브 SQL 이 어차피 필요.)
2. **ShedLock 제외**: Spring 7 호환 확인 못함 → PostgreSQL advisory lock 사용.
3. **MinIO 제외**: 보관됨(21번 §1-10). 개발 파일 저장은 R2 개발 버킷.
4. **Flutter**: 안정판 **3.47.8 / Dart 3.13.7**(공식 릴리스 JSON, 2026-10-23). `material_ui` 1.8.0·`cupertino_ui` 1.1.4 는 Dart ^3.13·Flutter ≥3.47 요구 → 정확히 맞음. 사용 패키지 12종의 SDK 요구가 모두 이 안정판 이하(스크립트 확인).
