- **외부 사실 미검증**: 요금·무료 한도·최신 버전·Play 정책·법령 조문/개정·2025/2026 최저시급 고시값은 이 환경에서 확인하지 못했다(문서에 확인 필요 표시).
- **코드 미구현**: Spring/React/Flutter 코드의 빌드·성능·QR·서명 UX 는 미검증이다. 검증된 것은 DB 규칙(제약·뷰·동시성)과 문서 정합이다.
- **해석 8건(98번 §3)** 은 사용자 확인 전까지 가정이다.
- **법률·세무 자문 아님.** 주민번호 수집·보관 구조는 특히 전문가 확인이 필요하다.
- 시/군/구 지역 마스터와 은행별 대량이체 양식은 원본 데이터/양식 확보 후 적재해야 한다.
