# 09. 화면 설계서
> 이 문서는 `tools/spec/*.py` 와 `db/schema.sql` 에서 `python3 tools/build_docs.py` 로 **자동 생성**된다. 직접 수정하지 말고 원천 데이터를 고칠 것.
> 버전 v1.0 · 기준일 2026-10-28

## 0. 설계 기준
- 디자인 원칙·토큰·컴포넌트는 `15_UI_UX_디자인시스템.md` 를 따른다. 출연자 앱은 **토스·당근 같은 간결하고 따뜻한 모바일 UX**, 웹은 shadcn/ui 기반의 깔끔한 업무 화면.
- 모든 화면은 **로딩(스켈레톤) · 빈 상태 · 오류(재시도) · 오프라인** 4가지 상태를 가진다.
- 위험한 동작(합격 취소, 노쇼 처리, 엑셀 다운로드, 마감)은 확인 바텀시트/모달 + 영향 요약(몇 명이 바뀌는지)을 보여준다.
- 와이어프레임은 핵심 화면만 ASCII 로 표현했고, 디자인 시안(Figma)은 이 문서의 컴포넌트·상태 정의를 입력으로 제작한다.

## 3. 공통 상태 배지 (색은 15번 문서 토큰)
| 상태 | 문구 | 색 |
|---|---|---|
| APPLIED | 지원 완료 | 중립(gray) |
| SHORTLISTED | 검토 중 | 파랑 |
| WAITLISTED | 예비 합격 | 보라/노랑 |
| CONFIRMED | 합격 | 초록 |
| REJECTED / AUTO_REJECTED | 불합격 / 마감 | 회색(경고색 사용 금지, 상처 최소화) |
| CANCELED_* | 취소 | 회색 취소선 |
| 참석 확인 | 확인됨 / 미응답 | 초록 / 주황 |
| 출석 | 출석 / 지각 / 노쇼 | 파랑 / 주황 / 빨강 |
