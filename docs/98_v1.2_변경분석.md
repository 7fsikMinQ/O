## 3. 아직 사용자가 정해야 하는 것
1. **H7 해석 확인**: 일정 최대 21일이 맞는지.
2. **iPhone 웹 경험 허용 수준**: W2 검증에서 Flutter 웹 로딩이 느리면 (a) 출연자 웹만 React 로 별도 개발 (b) iOS 앱을 일찍 출시(Apple 연 US$99) 중 선택.
3. **중요 알림 문자 폴백**: 옵트인 사용자에게 문자(18원)/알림톡(13원)을 쓸지 — 비용 부담 주체(무료 운영 중 운영자 부담).
4. 법무: 주민번호 수집·보관 구조(13번 §5-1), 직업정보제공사업 신고(§5-4).
5. 도메인·상표 조회(가용성 미확인).
