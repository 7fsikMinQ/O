# 24. 개발 착수 순서 — "도커부터? compose 부터?"

**답: Docker 도, compose 도 첫 단계가 아니다.** 순서는 ① 버전 확인 → ② 저장소 뼈대·문서 → ③ DB(compose) → ④ 백엔드 → ⑤ 웹 → ⑥ 앱. compose 는 ③(DB 를 띄워야 백엔드 마이그레이션·시험이 돈다).

## 이미 끝난 것 (이 저장소 현재 상태, 실행 전)
| 단계 | 산출물 | 상태 |
|---|---|---|
| ① 버전 | `docs/23`, `tools/check_versions.sh` | ✔ 전부 통과(실행 없이 레지스트리 확인) |
| ② 뼈대 | `backend/ web/ app/ infra/ .github/ README.md .gitignore .editorconfig`, `tools/sync_migration.sh` | ✔ 파일 작성 |
| ③ DB | `infra/docker-compose.dev.yml`(PG 18, 메일함), Flyway `V1__baseline.sql`(=schema.sql) | 작성, 실행 전 |
| ④ 백엔드 | Boot 뼈대: 보안 기본 거부, `/features`, `/app/config`, 기능 플래그 게이트, 시험 3개 | 작성, 실행 전 |
| ⑤ 웹 | React 뼈대(토큰 CSS, `/features` 호출 화면) | 작성, 실행 전 |
| ⑥ 앱 | Flutter 뼈대(토큰, 쉬운 말 사전, 테마) | 작성, 실행 전 |

## 현재 상태
슬라이스 1(문자 인증 가입·로그인) 완료(사용자 WSL2 에서 17건 통과), 슬라이스 2(프로필·계좌·주민번호·사진) 완료(시험 36건, PG 18 Docker 포함). 다음은 업체 등록·승인. 설치·브랜치는 25번.

## 실제 테스트 결과 요약
5회 정적 검토 후 실행: 백엔드 컴파일·단위 시험·기동 스모크, 웹 lint/test/build, 앱 analyze/test/web build 모두 통과(상세 23번 §6). Docker 가 필요한 시험 5건과 JDK 25·PG 18 확인은 로컬/CI 에서 남음.

## 로컬(WSL2)에서 같은 것을 하는 순서
1. `tools/dev/up.sh` → DB 기동.
2. 백엔드: Gradle 래퍼 생성(`gradle wrapper --gradle-version 9.8.2`) → `./gradlew test`(Testcontainers 는 Docker 필요) → `bootRun`.
3. 웹: `npm install`(락 파일 생성) → `npm run lint && npm test && npm run build`.
4. 앱: Flutter SDK 3.47.8 설치 → `flutter pub get && flutter analyze && flutter test`.
5. 통과하면 수직 슬라이스 시작(CLAUDE.md §9-3): auth(문자 OTP) → 프로필 → 업체 승인 → 공고 → …

## WSL2 에서의 위치
저장소는 WSL 리눅스 홈(`~/work/O`)에. Docker Engine 은 WSL 안. Flutter 는 Windows 쪽(12번 §0).
