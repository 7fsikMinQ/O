## 남은 공백 (정직한 목록)
- 오픈 전 필수: 관리자 TOTP(지금은 DB 고정 2차 비밀번호), 실제 SMTP+SPF/DKIM/DMARC, Turnstile, `login_histories` 정리 배치, R2 파일 어댑터, FCM 푸시, 비밀번호 변경 뒤 액세스 토큰 15분 유효, 가입 시 "이미 가입" 노출.
- 사용자 결정으로 보류·생략: 문자 대행사 연결(비용·계약), 법무 확인(서비스가 중개·지원서만 다루고 근로계약서·임금 지급이 없다는 판단 — 다만 주민번호 보관은 개인정보보호법 사안이라 구조는 유지, 13·17번).
- 미검증: iPhone 실기기(W2 게이트), Docker 가 필요한 Testcontainers 시험(`MigrationIT`)은 사용자 WSL 에서 실행.
