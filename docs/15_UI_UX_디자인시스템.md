# 15. UI/UX 디자인 시스템 (v1.3)

> 2026-10-28 · 목표: 출연자 앱은 **토스·당근처럼 간결하고 따뜻한 모바일 UX**를 **파스텔 톤**으로, 이모지로 친근하게. 라이트/다크 모두 제공. 업체/관리자 웹은 같은 토큰을 쓰는 정돈된 업무 UI.
> ⚠️ 토스·당근의 **로고·아이콘·전용 폰트·브랜드 색을 복제하지 않는다.** "느낌"(원칙·밀도·모션)만 참고한다. 서비스명은 **보조출연 헬프**(표시명, `app_settings.service_name`), 로고는 **공란**(추후, 교체 지점만 준비).

## 1. 디자인 원칙
| 원칙 | 의미 | 적용 |
|---|---|---|
| 한 화면 한 목적 | 핵심 행동 1개 | 하단 고정 CTA(56dp) 1개, 보조는 텍스트 버튼 |
| 큰 글씨·넓은 여백 | 눈이 편하고 실수 감소 | 본문 16sp↑, 카드 패딩 16~20, 섹션 간격 24 |
| 숫자·상태 먼저 | 현장 판단에 필요한 정보 | 시급·집합시각·남은 인원을 카드 상단에 굵게 |
| 단계적 폼 | 한 번에 다 묻지 않기 | 지원 3단계(정보→사진→서명), 자동 입력 |
| **이모지 버튼/배지** | 읽지 않아도 이해 | `✍️ 지원하기`, `✅ 확정하기`, `🎉 합격`, `⚠️ 겹침`, `📷 촬영`, `🌙 심야`, `🏕 숙박` |
| 따뜻한 말투 | 거절도 상처 최소화 | "이번엔 선발되지 않았어요 🍃" (빨강 금지) |
| 신뢰 신호 | 안전한 서비스 느낌 | 업체 승인 배지, 활동 횟수(점수 없음) |
| 즉각 피드백 | 기다림 최소화 | 스켈레톤, 낙관적 업데이트, 실행 취소 토스트, 햅틱 |
| 실수 방지 | 위험 동작 확인 | 영향 인원 수를 보여주는 확인 시트 |

## 2. 디자인 토큰 (파스텔 · 명도 대비 계산 완료)

## 4. 구현 가이드
### Flutter (출연자 앱 + 웹)
- `ThemeData(useMaterial3: true)` + `ColorScheme` 를 위 토큰으로 직접 지정(라이트/다크), 추가 토큰은 `ThemeExtension<AppTokens>`. 위젯 레이어 `core/ui` 를 먼저 만들고 화면은 조립만(색/크기 하드코딩 금지).
- **한 코드로 Android + 웹(PWA)**: 터치 우선 레이아웃, 웹에서는 최대 폭 480px 중앙 정렬(데스크톱에서도 모바일 UI 유지), `flutter build web`(기본 CanvasKit; Wasm 은 iOS 브라우저 미지원).
- 달력 `table_calendar` + 커스텀 빌더(다일 막대), 목록 `SliverList` + 스켈레톤, 이미지 `cached_network_image`.
- 푸시 딥링크 경로: `/applications/:id`, `/applications/:id/confirm`, `/conflicts/:id`, `/messages/:threadId`, `/field/schedules/:id/attendance`.
- 접근성: Semantics, 글자 1.3배 테스트, 터치 타겟 점검.
### 웹 (업체·관리자)
- Tailwind v4 CSS 변수에 위 토큰, shadcn/ui 가 참조. (MUI 도 같은 토큰으로 가능하나 번들·커스터마이징·무료 정책 면에서 shadcn 기본. MUI X Pro/Premium 유료 기능 금지.)
- 지원자 그리드(TanStack Table): 밀도 토글, 키보드 단축키(선택/합격 통보), 모바일에서는 카드 폴백. 인쇄용 스타일(인원표·정보표).

## 부록. 목업과 자동 점검 (v1.3)
- 목업: `docs/mockups/` (`tokens.css` 토큰, `app.html`/`app_dark.html` 출연자 앱 6화면, `web.html`/`web_dark.html` 업체 인원 정보표, `shot_*.png` 스크린샷). 목업은 **HTML 시안**이며 실제 Flutter 구현이 아니다 — Flutter 화면은 W2 이후 iPhone/Android 실기기로 다시 본다.
- 자동 점검: `NODE_PATH=$(npm root -g) node tools/check_mockups.js [--shots]` — 글자 대비(WCAG 4.5/큰 글씨 3), 터치 대상 ≥44px, 글자 ≥12px, 가로 넘침, 큰 글씨 배율. 현재 라이트/다크 모두 통과.
- 검토에서 고친 것: 공고 카드 보수 줄이 칩과 한 줄에 있어 어색하게 줄바꿈 → 칩을 아래 줄로, 한글 `word-break: keep-all`.
- 남은 한계: 눈으로 본 것은 스크린샷 기준이며 실제 사용자 반응·실기기 렌더링(Pretendard, iOS Safari)은 미검증.
- **v1.3 개정(40~50대)**: 기본 글씨 18px·보조 15px·버튼 56px, 쉬운 말([19번](./19_쉬운말_UI_가성비_편의성_계획.md)), 합격서에 금액 없음·예상 시간 안내. 점검 기준 글자 ≥14px·터치 ≥48px. 생성기 `tools/build_mockups.py`.
