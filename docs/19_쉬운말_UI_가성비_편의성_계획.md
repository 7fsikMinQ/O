# 19. 40~50대용 쉬운 한국어 UI · 서버 선택 — 가성비 vs 편의성 계획 (v1.3)

> 대상: 출연자 상당수가 40~50대. "쉬우면서 싸게". 가격은 [16번](./16_외부사실_확인표.md)·[18번](./18_운영서버_보안_가이드.md) 기준(재확인 필요).

## 1. 시간·보수 표시 원칙 (사용자 확정)
| 화면 | 표시 | 하지 않는 것 |
|---|---|---|
| 공고 | 집합 "아침 6시쯤 (±2시간)", 끝나는 때 "저녁 6시쯤 (±4시간)", 시급(최저시급 옵션)만 | 정확한 종료 시각, 총액 약속 |
| 합격서 | 현장·역할·모이는 때(±2h)·끝나는 때(±4h) + "예상이며 확정 아님·변동·추가 연장 가능", "보수는 공고 확인", "근로계약서는 현장에서" | **금액 항목 없음** |
| 합격 알림·확정 화면 | 같은 안내 문구 | |
- 허용 오차는 일정별 `gather_tolerance_minutes`(기본 120)·`end_tolerance_minutes`(기본 240), 문구는 `app_settings.time_estimate_notice`. 내부 `start_at/end_at` 은 겹침·QR·리마인더 계산용.
- 겹침 판정은 예상 시간 기준이며 간격 버퍼(기본 120분)가 있어 오차를 일부 흡수한다. 오차가 커서 실제로 겹칠 수 있는 일정은 "변동 가능" 경고 문구를 함께 보여 준다.

## 2. 쉬운 말 용어 사전 (화면·알림·문서 공통)
| 시스템 용어 | 화면에 쓰는 말 |
|---|---|
| 합격 통보(SELECTED) | "뽑혔어요" |
| 확정(CONFIRMED) | "참여할게요" 누름 → "참여 확정" |
| 불합격/자동 마감 | "이번엔 함께하지 못해요 🍃" |
| 집합 | "모이는 때/곳" |
| 지원서 | "지원서" (유지) |
| 노쇼 | "안 나온 횟수" |
| 전자서명 | "서명하기" |
| 프로필 | "내 정보" |
| 겹침/충돌 | "다른 일과 시간이 가까워요" |
| 인증번호 | "문자로 온 숫자 6자리" |
- 한자어·영어 약어 금지(OTP, QR 은 "문자 숫자", "출근 확인 QR" 처럼 풀어 씀), 존댓말 해요체, 한 문장 한 가지.

## 3. UI 기준 (40~50대)
글씨 본문 18px·보조 15px 이상, 버튼 높이 56px(보조 48px), 한 화면 한 가지 일, 하단 큰 버튼 1개, 아이콘+글자 함께, 대비 4.5:1 이상, "글씨 크게 보기" 설정(시스템 글꼴 배율 1.3배까지 깨지지 않기), 오류는 **해야 할 일**로 안내("사진이 흐려요. 밝은 곳에서 다시 찍어 주세요"), 단계 표시(1/3), 되돌리기 쉬운 취소, 고객센터 **전화 연결** 버튼, 로그인은 문자 숫자 6자리(비밀번호 암기 없음, 한 번 로그인하면 오래 유지). 자동 점검: `tools/check_mockups.js`(글자 ≥14px, 터치 ≥48px, 대비). 실사용 확인: 40~50대 3명이 도움 없이 지원 완료(REQ-NFR15 인수기준).

## 4. 서버·인프라: 가성비 vs 편의성
| 구분 | 가성비 우선(권장 시작) | 편의성·안정 우선(성장 후) |
|---|---|---|
| 서버 | Lightsail 서울 2GB US$12 단일 | 4GB US$24 → DB 분리(관리형 DB) |
| 배포 | Docker Compose + 스크립트(수동 `git pull`·재시작) | CI 자동 배포, 무중단 교체 |
| 앱/웹 | Flutter 한 코드(앱+웹), 업체 웹 Cloudflare Pages(무료) | iOS 앱 스토어(연 US$99) |
| 인증 | 문자 숫자 6자리(건당 약 18원) | 카카오 전화번호 로그인 병행 |
| 알림 | FCM 무료 + 이메일 폴백 | 카카오 알림톡(건당 약 13원) |
| 파일 | R2 10GB 무료 | 용량 증가 시 소액 |
| 백업 | 일 1회 암호화 덤프 → R2 | 연속 백업(PITR) |
| 모니터링 | UptimeRobot 무료 | Sentry 등 |
| 고객 지원 | 전화·카카오 채널(운영자 직접) | 챗봇/상담 도구 |
**선택 기준**: 폐쇄 베타(업체 1곳)는 왼쪽 열 전부. 사용자가 늘거나 장애가 업무에 직접 영향 주면 오른쪽에서 **한 항목씩**만 올린다(문자 비용·사용자 수 지표 기준).
