# 04. 메뉴 구성도
> 이 문서는 `tools/spec/*.py` 와 `db/schema.sql` 에서 `python3 tools/build_docs.py` 로 **자동 생성**된다. 직접 수정하지 말고 원천 데이터를 고칠 것.
> 버전 v1.0 · 기준일 2026-10-28

## 설계 원칙
- **출연자 앱**: 하단 탭 5개(홈 · 공고 · 내 일정 · 알림 · MY). 한 화면 한 목적, 하단 고정 CTA, 바텀시트 필터(토스·당근 방식).
- **현장(반장) 모드**: 같은 앱의 계정 전환 스위치로 진입(업체 구성원 계정만 노출). 현장에서 한 손으로 쓰는 기능만 담는다(출석·미응답자·메시지·명단).
- **업체 웹**: 좌측 사이드바. 무거운 작업(공고 작성·지원자 비교·엑셀·정산)은 웹.
- **관리자 웹**: 업체 웹과 같은 SPA 의 별도 라우트(`/admin`), 권한이 있는 사용자에게만 노출.
- 우선순위 표시가 없는 화면은 P1(MVP). `(P2)`, `(P3)` 는 후속.

## 현장(반장) 모드 — 같은 앱 내 역할 전환
```text
현장
  ├─ 목록
    └ [SCR-F01] 현장 모드 진입·내 현장 목록
  ├─ 상세
    └ [SCR-F02] 현장 대시보드(인원표)
  ├─ 출석
    └ [SCR-F03] 출석 체크
  ├─ 참석확인
    └ [SCR-F04] 참석 미응답자 목록
  ├─ 퇴근
    └ [SCR-F05] 퇴근 세션·QR 스캔
  ├─ 메시지
    └ [SCR-F06] 단체 메시지 작성
  ├─ 명단
    └ [SCR-F07] 합격자 명단(간이 정보표)
  ├─ 출근
    └ [SCR-F08] 출근 세션·QR 스캔
  ├─ 취소판정
    └ [SCR-F09] 취소 패널티 판정(스케줄러)
```
