## 2. 저장소 구조 (모노레포)
```text
.
├─ CLAUDE.md                  # 프로젝트 기억·작업 지침 (AI 세션용)
├─ docs/                      # 설계 문서 (00~15, 98, 99)
├─ tools/                     # 문서 생성·검증 (build_docs.py, spec/, test_schema.sql)
├─ db/
│  ├─ schema.sql              # 전체 스키마 (단일 진실 원천, 문서 생성에 사용)
│  ├─ migration/              # Flyway V1__, V2__ ... (schema.sql 을 단계 분할)
│  └─ future/                 # 아직 적용하지 않는 확장 DDL 초안 (수익화 등)
├─ backend/                   # Spring Boot (Gradle 멀티모듈 or 단일 모듈+패키지 분리)
├─ web/                       # React + Vite (업체·관리자)
├─ app/                       # Flutter (출연자 + 현장 모드)
├─ infra/                     # docker-compose.dev.yml, 배포용 compose, nginx 설정
└─ .env.example
```

## 3. 최초 세팅 순서
```bash
git clone <저장소> && cd <저장소>
cp .env.example .env
docker compose -f infra/docker-compose.dev.yml up -d      # PostgreSQL 17, MinIO, Mailpit
```
```bash
# 스키마 적용 (프로젝트 초기에는 schema.sql 을 직접, 이후 Flyway)
psql "postgresql://app:app@localhost:5432/app" -v ON_ERROR_STOP=1 -f db/schema.sql
psql "postgresql://app:app@localhost:5432/app" -f tools/test_schema.sql    # 제약 동작 검증 (롤백됨)
```
```bash
# MinIO 버킷 생성 (콘솔 http://localhost:9001, 기본 minio/minio12345) : app-private, app-public
```

### 3.1 백엔드
```bash
cd backend
./gradlew bootRun --args='--spring.profiles.active=local'     # http://localhost:8080
./gradlew test                                                 # Testcontainers(PostgreSQL) 통합 테스트
```
- `application-local.yml` 은 `.env` 값을 읽는다. `spring.jpa.hibernate.ddl-auto=validate` (스키마는 Flyway/SQL 이 소유, JPA 가 생성 금지).
- 시간대: `spring.jackson.time-zone=UTC`, `hibernate.jdbc.time_zone=UTC`.
- 필수 의존성(요약): web, security, data-jpa, validation, actuator, flyway-core + flyway-database-postgresql, postgresql, querydsl, jjwt, springdoc-openapi, shedlock-spring + jdbc provider, apache-poi, aws-sdk-v2 s3, firebase-admin, testcontainers.
- 필수 코드 규칙: 모든 엔드포인트 권한 명시, 엔티티 직접 반환 금지, 민감정보 로그 금지, `Idempotency-Key` 처리, 확정 서비스는 03 부록 E 순서.

### 3.2 웹 (업체·관리자)
```bash
cd web && pnpm install
pnpm gen:api            # springdoc /v3/api-docs → openapi-typescript 클라이언트 생성
pnpm dev                # http://localhost:5173  (API 프록시 → :8080)
pnpm test && pnpm build
```
스택: React 19, TypeScript, Vite, TanStack Query/Table, Zustand, Tailwind, shadcn/ui, FullCalendar(`@fullcalendar/react`, `daygrid`, `interaction` 만), react-hook-form, zod, browser-image-compression.

### 3.3 앱 (Flutter)
```bash
cd app && flutter pub get
dart run build_runner build --delete-conflicting-outputs     # freezed/json 생성
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8080/api/v1      # 안드로이드 에뮬레이터
flutter test
```
- Firebase: 콘솔에서 프로젝트 생성 → Android/iOS 앱 등록 → `google-services.json`/`GoogleService-Info.plist` 배치(커밋 금지) → FCM 서비스 계정 키는 서버 시크릿으로.
- 카카오 로그인: Kakao Developers 앱 등록 → 네이티브 앱 키·플랫폼 키 해시 등록.
- 애플 로그인: Apple Developer 에서 Sign in with Apple 활성화(iOS 출시 시 필수).
- 폰트: Pretendard(SIL OFL) 를 `assets/fonts` 에 포함(15번 문서).

### 3.4 Cloudflare 설정 (운영/스테이징)
1. 도메인 DNS 를 Cloudflare 로 이전.
2. R2 버킷 2개(`private`, `public`) 생성, API 토큰(해당 버킷만) 발급, `public` 은 커스텀 도메인 연결 + CDN 캐시.
3. Pages 프로젝트에 `web/` 연결(빌드 `pnpm build`, 출력 `dist`).
4. Turnstile 사이트 키/시크릿 발급.
5. WAF 기본 관리 규칙·봇 방어 켜기.

## 4. 문서 생성·검증 (스키마/명세 변경 시 필수)
```bash
# 임시 DB 에 스키마를 적용한 뒤, 접속 가능한 psql 명령을 DOC_PSQL 로 지정
export DOC_PSQL='psql postgresql://app:app@localhost:5432/app -AtX -F "$(printf "\t")"'
python3 tools/build_docs.py          # 01,03,04,05,06,07,08,09 생성 + 연결 검증(오류 시 exit 1)
```
검증 항목: 요구사항↔기능↔화면↔API↔프로그램 연결 누락, ID 중복, API 의 테이블 존재, 우선순위 일관성, 문서 내 ID/식별자 참조.

## 5. 브랜치 · 커밋 · CI
- 브랜치: `main`(보호) ← `feature/*`. PR 필수, CI 통과 후 병합.
- 커밋: 변경 이유 중심. 스키마 변경은 `db/`·마이그레이션·문서 재생성을 한 PR 로.
- CI(GitHub Actions) 단계: ① 백엔드 테스트(Testcontainers) ② 웹 lint/test/build ③ Flutter analyze/test ④ 문서 생성 검증 ⑤ **라이선스 스캔**(Gradle license plugin, pnpm licenses, `flutter pub deps`) ⑥ 이미지 빌드·푸시 ⑦ (main) 배포.
- 시크릿 스캔(gitleaks 등) 활성화.

## 7. 자주 겪는 문제
| 증상 | 원인/해결 |
|---|---|
| 안드로이드 에뮬레이터에서 API 접속 불가 | `localhost` 대신 `10.0.2.2` |
| EXCLUDE 제약 생성 오류 | `CREATE EXTENSION btree_gist` 필요(관리형 DB 는 허용 확장 목록 확인) |
| 서명 URL 403 | 서버·스토리지 시계 오차, 버킷 CORS 에 `PUT` 허용 |
| 한글 파일명 깨짐 | 업로드 키는 UUID, 원본명은 `original_name` 에만 |
| Flutter iOS 푸시 미수신 | APNs 키 FCM 등록, 실기기 필요 |
| Flyway 체크섬 오류 | 적용된 마이그레이션 수정 금지 → 새 버전 추가 |
