# 98. v1.3 변경 분석

기준 2026-10-28. v1.2 → v1.3.

## 사용자 확정·요청
1. 일정 최대 21일(3주) 확정 — 길이는 중요하지 않음(변경 없음).
2. **근로계약서는 현장 실물**(출석 확인 후 교부). 서비스에는 **지원서 + 합격서**만 → 합격서 화면/PDF 추가(REQ-PC16), 근로계약서 기능 만들지 않음.
3. 임금은 업체가 일 끝난 뒤 출연자 계좌로 3.3% 공제 후 지급. 서비스를 통한 전달이 가능한지 분석 → **17번**: 플랫폼은 송금 안 함, 기록·파일 생성만, 전부 **플래그로 숨김**.
4. 개발 DB = 노트북 WSL2, 운영 서버·비용·보안·포트포워딩 → **12번 §0, 18번**.
5. 앱 UI 시안 검증 → `docs/mockups`, `tools/check_mockups.js`.

| 인프라 | dev compose: PostgreSQL 18, 모든 포트 127.0.0.1 바인딩 |

## 결정 근거 요약
- 돈을 플랫폼이 움직이면 전자금융업·자금 보관 책임이 생길 수 있어(❓ 확인 필요) **구현하지 않는다**. 계산·기록·이체 파일·지급 완료 기록은 만들되 OFF.
- 숨김은 서버에서 404 로 강제(UI 숨김만으로는 불충분).
- 운영 서버는 Lightsail 서울 US$12 + Cloudflare, 포트포워딩 불필요·금지.
